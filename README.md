# کلکسیون انیمه – نسخه اندروید

این پوشه یک بازنویسی مستقل از رابط وب Laravel/Livewire به اپلیکیشن HTML/CSS/JavaScript با Capacitor است.

## امکانات موجود در این نسخه اولیه
- ثبت، ویرایش و حذف انیمه
- روزهای پخش هفته به ترتیب شنبه تا جمعه
- نگهداری داده‌های انیمه در SQLite بومی اندروید
- تنظیم Cookie NineAnime با افزونه Secure Storage در APK
- رابط فارسی RTL با فونت Vazirmatn محلی و تم ساکورا
- تلاش برای استخراج لینک آخرین قسمت از Animex و NineAnime
- کپی لینک استخراج‌شده در کلیپ‌بورد

## نکات مهم و محدودیت‌های نسخه اولیه
- این یک نسخه اولیه قابل توسعه است، نه نسخه نهایی تأییدشده. هنوز روی دستگاه اندرویدی واقعی آزمایش نشده است.
- در مرورگر دسکتاپ از localStorage فقط برای پیش‌نمایش داده‌ها استفاده می‌شود؛ در APK دیتابیس SQLite است.
- Cookie در APK با افزونه Secure Storage ذخیره می‌شود. در پیش‌نمایش مرورگر، Cookie فقط در sessionStorage نشست فعلی می‌ماند و ذخیره امن نیست.
- استخراج‌کننده‌ها از منطق دامنه‌ها و الگوی فایل نسخه PHP بازنویسی شده‌اند؛ تغییر HTML سایت‌ها، محدودیت دسترسی، Cloudflare یا نیاز به هدرهای خاص ممکن است استخراج را متوقف کند.
- درخواست‌های شبکه از CapacitorHttp استفاده می‌کنند تا در WebView اندروید به CORS مرورگر وابسته نباشند؛ دسترسی واقعی به میزبان‌ها باید روی گوشی آزمایش شود.
- داده‌ها روی همان نصب برنامه ذخیره می‌شوند و سرور یا حساب کاربری ندارند.
- برای گرفتن لینک تازه اینترنت لازم است؛ مشاهده و مدیریت کلکسیون ذخیره‌شده آفلاین است.

## پیش‌نیازها
- Node.js نسخه 22 یا جدیدتر
- Git
- Android Studio روی کامپیوتر لازم نیست؛ GitHub Actions فایل APK آزمایشی را می‌سازد.
- برای build محلی Android به JDK و Android SDK نیاز است.

## اجرای پیش‌نمایش وب
```bash
npm install
npm run build
```
فایل‌های خروجی در `dist/` ساخته می‌شوند. اجرای پیش‌نمایش توسعه:
```bash
npx vite --host 0.0.0.0
```

## ساخت APK با GitHub Actions
1. کل محتویات این پوشه را در ریشه مخزن GitHub پروژه قرار بده.
2. Commit و Push به شاخه `main` انجام بده.
3. GitHub → Actions → `Build Android APK` → آخرین اجرای موفق.
4. در بخش Artifacts فایل `anime-collector-debug-apk` را دانلود کن.
5. فایل ZIP دانلودشده شامل `app-debug.apk` است.

Workflow با هر Push به main و همچنین با اجرای دستی فعال می‌شود. GitHub ممکن است محدودیت مصرف رایگان Actions داشته باشد.

## مجوز و حریم خصوصی
- هر نصب اپ داده‌های محلی خودش را دارد.
- اطلاعات کلکسیون به هیچ سروری ارسال نمی‌شود.
- Cookie را در مخزن GitHub یا فایل‌های پروژه قرار نده.
- این نسخه از debug APK استفاده می‌کند؛ برای انتشار عمومی گسترده باید APK/AAB امضاشده و فرایند انتشار جداگانه تنظیم شود.
