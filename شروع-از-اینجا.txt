نسخه اندروید کلکسیون انیمه – راهنمای خیلی کوتاه

۱) این ZIP یک پروژه اندرویدی مستقل است؛ فایل‌های اصلی Laravel در پوشه legacy-laravel نگهداری شده‌اند.
۲) فایل‌ها و پوشه‌های داخل ZIP را در ریشه مخزن GitHub پروژه کپی کن. پوشه .git موجود در کامپیوترت را حذف نکن.
۳) فایل workflow جدید در مسیر .github/workflows/build-android.yml است.
۴) تغییرات را با GitHub Desktop Commit و Push کن.
۵) در GitHub وارد Actions شو، اجرای Build Android APK را باز کن و پس از موفقیت، Artifact با نام anime-collector-debug-apk را دانلود کن.
۶) ZIP آرتیفکت را باز کن؛ فایل app-debug.apk داخل آن است.

مهم:
- هیچ Cookie، فایل .env، رمز یا کلید محرمانه را به GitHub نفرست.
- این نسخه اولیه هنوز روی گوشی واقعی آزمایش نشده است. پس از اولین ساخت، ابتدا روی گوشی خودت آزمایش کن.
- استخراج لینک به اینترنت نیاز دارد. مدیریت فهرست ذخیره‌شده آفلاین است.
- در APK، اطلاعات انیمه در SQLite محلی و Cookie با افزونه ذخیره‌سازی امن اندروید ذخیره می‌شود.
